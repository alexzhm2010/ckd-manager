# 🫘 个人肾病管理平台 (CKD Manager)

一个纯前端、零依赖部署的**慢性肾脏病（CKD）个人管理工具**，专为长期追踪肾功能、用药依从性与复查节奏设计。适合 CKD 3-5 期患者日常自我管理使用。

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 🏠 首页 | 核心指标卡（eGFR/肌酐/尿蛋白/血钾，超标自动标红）、智能病情提醒、每日用药打卡、逾期复查待办 |
| ✍️ 记录 | 血压（≥140/90 自动预警）、饮水、体重+水肿、血钾症状自查（勾选≥2项弹就医警示）、症状备注 |
| 📈 指标 | 18 项指标互动趋势图（ECharts），带参考范围标线，支持手动录入新化验值 |
| 💊 用药 | 用药方案清单、近 7 天服药依从性图、用药安全红线（禁用药物提示） |
| 🏥 复查 | 复查倒计时、复查项目频率管理（自动判断逾期/临近）、就诊问题清单 |
| 📚 知识 | CKD 饮食红线（限盐/限钾/优质低蛋白/低嘌呤）、紧急就医信号、疾病知识 |

## 🚀 使用

纯静态页面，无需构建、无需后端：

- **本地**：直接双击 `index.html` 打开
- **在线**：GitHub Pages 部署后手机浏览器直接访问

数据存储在浏览器 `localStorage`，**不上传任何服务器**。换设备时数据不自动同步。

## 📁 文件

```
├── index.html   # 应用主体（单文件，内含全部样式与逻辑）
└── history.js   # 预置的检验指标历史数据（可替换为自己的数据）
```

### 替换为自己的数据

编辑 `history.js`，格式如下（key 含义见 `index.html` 中的 `META` 对象）：

```js
const HISTORY = {
  crea: [{date:"2025-11-15", v:303}, {date:"2026-10-24", v:263}],
  egfr: [{date:"2025-11-15", v:22}],
  // ...
};
```

用药列表在 `index.html` 的 `MEDS` 数组中修改。
